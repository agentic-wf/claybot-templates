# Comment format

Thank the reporter in a few words the first time, not on every reply.

```
Thanks for the report!

**Type:** bug · **Severity:** medium · **Suggested labels:** `bug`, `area/payments`

<one line: your reading of the issue, if it was ambiguous>

**Possible duplicate:** #97 — <why it is the same cause>. If so, we'll continue there.

**To look into this, could you share:**
- <the one to three things actually missing>
```

Drop any section that has nothing in it. When labels were applied, write
**Labels:** instead of **Suggested labels:**. For a question you answered, the
answer replaces the checklist.
