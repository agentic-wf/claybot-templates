# Triage an issue

1. Read the issue title, body, and any logs or screenshots.
2. Classify it: bug, feature request, question, or docs.
3. Search open and recently closed issues for duplicates. Link the best match
   if there is one.
4. For a bug, check that it says how to reproduce it, what was expected, and
   the version. Ask for whatever is missing, in one list.
5. For a question you can answer from the code or docs, answer it.
6. Reply with one comment:
   - **Type**: the classification, and a suggested label.
   - **Duplicate of**: the link, if any.
   - **Next step**: what the reporter or a maintainer should do.

Never close, lock, or assign. A maintainer makes those calls.
