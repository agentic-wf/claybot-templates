# Release notes

Ask for the next release's notes and it collects every pull request merged
since the last tag, drops the noise, groups the rest (new, improved, fixed,
breaking), rewrites each title for users, and flags anything that needs an
upgrade step. It matches your CHANGELOG's existing style, and can open a pull
request adding the section.

**Needs:** the repositories it works on; a `GITHUB_TOKEN` for private ones.
