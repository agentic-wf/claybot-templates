# Formatting by platform

Use the platform the turn names when it names one, or the one you have seen
this thread use. When you do not know, write plain text with `code` spans and
`-` lists and stay under 2,000 characters: that reads correctly everywhere.

## Slack
- Bold `*text*`, italic `_text_`, strike `~text~`, code `` `x` `` and fenced blocks.
- Links `<https://example.com|label>`. Lists with `•` or `-`.
- No headings, no tables — use bold lines and short lists instead.
- Keep a reply under ~3,000 characters; longer replies get truncated in
  previews and are hard to read in a thread.

## Discord
- Standard Markdown: `**bold**`, `*italic*`, `` `code` ``, fenced blocks with a
  language, `> quotes`, `-` lists, `#` headings (sparingly).
- **Hard limit: 2,000 characters per message.** Stay well under it.
- Links as bare URLs; wrap in `<…>` to suppress the preview.

## Telegram
- Keep formatting minimal: plain text, `code`, and short lists read reliably.
- **Hard limit: 4,096 characters per message.**
- No tables; long code belongs in a file, not the chat.
