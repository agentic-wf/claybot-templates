# Bug severity

| Severity | When |
|---|---|
| critical | Data loss or corruption, a security hole, or the product unusable for most users, with no workaround. |
| high | A core feature broken for many users, or any user blocked, with no reasonable workaround. |
| medium | A feature broken or wrong with a workaround, or broken for a narrow set of users. |
| low | Cosmetic, a rough edge, or an unlikely edge case. |

When in doubt between two, pick the lower and say what would raise it
("high if this also affects …"). A suspected security issue should not be
discussed in detail in public: say a maintainer will follow up, and point to
the repository's SECURITY.md if it has one.
