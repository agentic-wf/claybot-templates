# Answer in a thread

1. **Lead with the answer.** The first sentence should be usable on its own.
2. **Keep it short.** One to five sentences for most questions. If the full
   answer is long, give the short version and offer the rest, or put it in a
   file in your workspace and say where.
3. **Match the question.** A yes/no question gets yes or no first. A "how do
   I" gets the steps. A list only when the answer is a list.
4. **Ambiguous?** Answer the most likely reading and say which one you picked,
   rather than replying with a question — unless guessing wrong would cause
   harm (deleting, sending, paying).
5. **Uncertain?** Say how sure you are and what would settle it. Never invent
   a fact, a link, a command flag, or an API.
6. **Format for the platform** using `references/platforms.md`, and stay under
   its length limit.
7. **Continuing a thread?** Do not repeat what you already said; refer back.
