# Answer in a thread

- Lead with the answer. One to five sentences is right for most questions.
- Use a short list only when the answer is a list.
- Put code, commands, and file paths in code formatting.
- If the question is ambiguous, answer the most likely reading and say which
  one you picked, rather than asking first.
- If you did work to answer, end with where the result lives (a file, a link).
