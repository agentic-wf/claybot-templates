# Weekly report

Every Monday morning (or the first morning after, if the agent was
asleep): what shipped last week across the repositories
this agent works on, what is stuck (pull requests waiting on review, issues
with no reply), what got opened versus closed, and the decisions waiting on
someone. One screen, grouped by theme rather than by repository.

**Needs:** the repositories it works on; a `GITHUB_TOKEN` for private ones.
Connect Slack, Discord, or Telegram after Create to get it there.
