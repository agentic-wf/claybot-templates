# Issue types and what each needs

## Bug — something that worked, or should work, does not
Needs, and ask only for what is missing:
- steps to reproduce, ideally minimal;
- what was expected and what happened instead;
- version (release, commit, or package version) and environment (OS, runtime);
- logs, stack trace, or error text, as text rather than a screenshot.

## Feature request — something new
Needs: the problem it solves (not only the proposed solution), who has it, and
what they do today instead.

## Question — how do I …
Needs: what they tried. Often answerable directly from the code or docs.

## Documentation — docs are wrong, missing, or unclear
Needs: the page or file, and what is wrong or missing.

## Not actionable
Spam, an empty body, or a support request for a different project. Say so
kindly and point to the right place if you know it.
