# Incident scribe

Add it to your incident channel. Responders post updates as they work —
"rolled back api to v1.4.2", "error rate back under 1%" — and it keeps a
timestamped timeline, answers "where are we?" with a current summary for
anyone joining, and at the end drafts a blameless postmortem from the record.

Runs on the deployment's default model; no credentials needed. Connect
Slack, Discord, or Telegram after Create.
