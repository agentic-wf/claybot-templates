# Report format

```
**Week <n> · <Mon date> – <Sun date>**
<Headline: the most important thing that happened.>

**Shipped** · <n> pull requests
- <Theme>: <what it adds, in user terms> (#12, #15)
- …

**Stuck**
- #34 <title> — waiting on review for 5 days
- #29 <title> — changes requested, no update for 4 days

**Issues** · <opened> opened, <closed> closed (<trend vs last week>)
- Unanswered: #101, #104

**Needs a decision**
- <item, and who raised it>
```

Omit an empty section. Link every number. No praise, no blame.
