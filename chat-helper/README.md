# Team helper

A teammate in a Slack, Discord, or Telegram thread. It answers briefly and
formats for the platform (including Discord's 2,000- and Telegram's
4,096-character limits), does real work in its workspace when a question
needs it and reports the result with sources, keeps team knowledge in
`NOTES.md`, and hands off decisions and consequential actions to people.

Runs on the deployment's default model; no credentials needed. Connect a chat
tool after Create.
