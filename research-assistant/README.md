# Research assistant

Ask a question — "which vector databases support hybrid search?", "what
changed in the EU AI Act's final text for general-purpose models?" — and get
a brief: the answer first, the evidence with links, how confident it is, and
what it could not confirm. Full notes stay in the workspace.

Works best on a harness with web search and fetch (Claude Code, the
recommended runtime); elsewhere it reads pages with `curl`.
