# Digest format

```
**<repo> · <branch> · <date range>**

<Headline: one sentence on the most important change.>

**Features**
- <What it does for a user or developer> — <author> (#123, abc1234)

**Fixes**
- …

**Internal** · <n> changes: <two or three words each, comma-separated>

**Watch out**
- <risk, and which change carries it>

<n> merges, <n> authors. Dependency updates: <n>.
```

Omit an empty group. Cite pull request numbers when there is one, and short
SHAs otherwise. Write each bullet for someone who did not read the code.
